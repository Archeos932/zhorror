# BOURDONNEMENT - le jeu, pret a jouer

Construit automatiquement depuis `main` (5727d3d), build 9. Ne pas modifier cette branche a la main.

- **Windows** : telecharge [`bourdonnement.exe`](https://github.com/Archeos932/zhorror/raw/release/bourdonnement.exe) et lance-le
  (si Windows avertit : *Informations complementaires* > *Executer quand meme*).
- **macOS** : [`Bourdonnement-macOS.zip`](https://github.com/Archeos932/zhorror/raw/release/Bourdonnement-macOS.zip) (premier lancement : clic droit > Ouvrir).
- **Linux** : [`Bourdonnement-Linux.tar.gz`](https://github.com/Archeos932/zhorror/raw/release/Bourdonnement-Linux.tar.gz)
  puis `tar xzf Bourdonnement-Linux.tar.gz && ./Bourdonnement-Linux/bourdonnement`.

Ensuite, le bouton **MISE A JOUR** du menu installe tout seul les nouvelles versions.
